# Verification Quickstart

Follow the [README](../../README.md#frontend-setup-and-development) to start the backend and frontend using the same browser origin. Sign in, create a project, record a session, and compare the entry in Daily Timeline and Project Journey Review.

Run the [frontend verification](../../README.md#frontend-verification) and [backend verification](../../README.md#testing-and-build). Browser automation uses its own disposable PostgreSQL database. For the full review, check all acceptance criteria in the [specification](spec.md).
